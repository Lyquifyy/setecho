# Chalkline — agent instructions

A coach that remembers every rep. Built for the Meta Global AI Developer Hackathon (Oct 26 – Nov 4, 2026, indie track).
Plan of record: "Meta Hackathon Build Plan" (Claude Docs). If this file and the plan disagree, the plan wins.

## Layout
- `backend/` — Python 3.12, uv, FastAPI. Stateless: holds the API key, measures, returns JSON. Logs live on the phone.
  - `app/meta.py` — the ONLY module that calls Meta Model API. Nothing else imports `openai`.
  - `scripts/` — live probes (`smoke.py`, `sam_probe.py`). Cost money; run deliberately.
  - `tests/fixtures/` — saved raw SAM / Spark output. Build measurement math against these.
- `ios/` — SwiftUI, iOS 26+, project generated by XcodeGen from `ios/project.yml`. Never edit the .xcodeproj.

## Commands
- `make test` — offline tests. Must pass before every commit.
- `make lint` — ruff.
- `make dev` — run the API on 0.0.0.0:8000.
- `make smoke` — one live call.
- `make ios` — regenerate + open Xcode. After adding Swift files, rerun `xcodegen generate`.

## Rules
1. Every model call goes to Meta Model API (`https://api.meta.ai/v1`): `muse-spark-1.3` for reasoning/parsing, `sam-3.1` for tracking. No other model providers in product code.
2. Key from `MODEL_API_KEY` env only. Never write keys, `.env` files, or clips into the repo.
3. Standard tier only (contributor-tier data can be used by Meta; footage contains bystanders).
4. Tests never hit the live API. Use fixtures in `tests/fixtures/`.
5. Numbers come from code, never from the model. The coach gets numbers via tool calls; the backend verifies every cited set id and timestamp before returning.
6. Measurement math lives in Python (OpenCV, NumPy, SciPy), not Swift.
7. Use real video timestamps for velocity; iPhone video can be variable frame rate.
8. Commit small and often with clear messages; the commit history is part of the submission.
9. Brand: iron #111312, chalk #F3F1EA, muted #A7AAA4, signal orange #FF6A2B (bar path, actions, warnings only). Barlow / Barlow Condensed.
